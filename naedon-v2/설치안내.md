# 내돈내가 신청 접수기 설치 (약 5분, 한 번만)

신청서는 **구글 시트**에, 올린 자료는 **구글 드라이브 폴더**에, 새 접수 알림은 **itart@finitart.com 메일**로 들어오게 합니다.
itart@finitart.com 구글 계정으로 로그인한 상태에서 진행하세요.

## 1. 스크립트 만들기
1. https://script.google.com 접속 → **새 프로젝트**
2. 왼쪽 위 「제목 없는 프로젝트」를 눌러 이름을 **내돈내가 접수기**로 바꿉니다.
3. 편집기 안의 내용을 모두 지우고, **Code.gs** 파일 내용을 통째로 붙여넣은 뒤 💾 저장합니다.
4. 왼쪽 ⚙ 프로젝트 설정 → 시간대가 **(GMT+09:00) 서울**인지 확인합니다.

## 2. 폴더·시트 자동 생성
1. 편집기 위쪽 함수 선택 칸에서 **setup** 을 고르고 ▶ **실행**
2. 「권한 검토」 창이 뜨면 → 계정 선택 → 「고급」 → 「내돈내가 접수기(으)로 이동」 → **허용**
3. 아래 실행 로그에 **자료 폴더**와 **접수 시트** 주소가 나오면 성공입니다. 드라이브에 「내돈내가 접수」 폴더가 생깁니다.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. ⚙ 유형 선택 → **웹 앱**
3. 설명: `내돈내가 v1` · 실행 사용자: **나** · 액세스 권한: **모든 사용자**
4. **배포** → 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> 「모든 사용자」는 신청자가 구글 로그인 없이 보낼 수 있게 하는 설정입니다. 시트와 폴더는 사장님 드라이브에 **비공개**로 남고, 신청자는 접수 결과(접수번호)만 받습니다.

## 4. 사이트에 연결
1. GitHub의 FinITArt 저장소 → `naedon/assets/config.js` 열기 → ✏️ 편집
2. `endpoint: ''` 의 따옴표 안에 복사한 URL을 붙여넣습니다.
   ```js
   endpoint: 'https://script.google.com/macros/s/AKfy.../exec',
   ```
3. **Commit changes** → 1~2분 뒤 반영됩니다.

URL을 넣기 전까지 신청 화면은 「메일 앱으로 보내기」 방식으로 동작합니다(자료는 직접 첨부).

## 5. 확인
- https://finitart.com/naedon/apply.html 에서 테스트로 한 건 신청 → 접수번호가 나오면 성공
- 시트에 한 줄이 추가되고, 자료를 올렸다면 「내돈내가 접수/접수번호」 폴더가 생기며, 알림 메일이 옵니다.
- 테스트 행과 폴더는 지워도 됩니다.

## 운영 메모
- 시트의 **처리 상태**(접수/검토 중/회신 완료/보류)와 **회신 분류**(①②③)는 목록에서 골라 관리합니다.
- 시효 표시가 있는 신청은 줄 전체가 연한 빨간색으로 표시되고, 메일 제목에 `[시효 …]`가 붙습니다.
- 보관 기간 약속은 **회신 후 6개월**입니다. 매달 한 번 오래된 폴더와 행을 지워 주세요.
- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 해야 반영됩니다. URL은 그대로 유지됩니다.
- 한도: 파일 8개 · 합계 20MB(사진은 신청 화면에서 자동으로 줄여 올림) · 사진·PDF만 허용.
- 무료 계정의 메일 발송 한도는 하루 약 100통입니다(Workspace 계정은 더 많음).
